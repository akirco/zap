# zap （开发中...）

终端文件浏览器,三栏（父目录 / 当前目录 / 预览），纯事件驱动重绘。

目标是超级轻量，也可能做成fzf那样的胶水层,灵感来源于去年开发一半的`github gist`TUI 笔记程序，抽取了ui逻辑，导航+预览可以是任何可扩展的程序。所以它不会是另一个`yazi`。

## 按键

| 按键        | 作用                                         |
| ----------- | -------------------------------------------- |
| `j` / `↓`   | 下一项                                       |
| `k` / `↑`   | 上一项                                       |
| `l` / `→`   | 进入目录                                     |
| `h` / `←`   | 返回上级（焦点在当前栏时）                   |
| `Tab`       | 切换焦点：当前 → 预览 → 父目录               |
| `Ctrl-B`    | 显示/隐藏父目录栏                            |
| `r`         | 左右翻转布局                                 |
| `s`         | 上下翻转 header/footer                       |
| `/`         | 按名称过滤当前目录，`Esc` 取消               |
| `?`         | 在当前目录（或选中文件）里搜内容，`Esc` 取消 |
| `:`         | 挂起 TUI 执行 shell 命令，回车返回           |
| `Enter`     | 选中并退出，把路径打印到 stdout              |
| `q` / `Esc` | 退出                                         |
